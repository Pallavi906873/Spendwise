# SpendWise Backend

A Node.js + Express + TypeScript backend for SpendWise, a smart expense tracker. Built as part of the Thaariva Technologies internship program.

## Features

- REST API for managing expenses (Create, Read, Update, Delete)
- PostgreSQL database with `users`, `categories`, and `expenses` tables
- Input validation and proper error handling (400/404 responses)
- Automated tests with Jest + Supertest

## Prerequisites

- Node.js
- Docker + Docker Compose
