# SpendWise

SpendWise is a web and mobile expense management application built with a frontend, backend API, and PostgreSQL database.

## Tech Stack

- Frontend: React / Expo
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Containerization: Docker and Docker Compose
